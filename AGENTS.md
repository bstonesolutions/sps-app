# AGENTS.md

## Brand
Stone Property Solutions. Crimson #AF011A, white, slate grey.
Apple-sleek: restrained, confident, generous whitespace, real hierarchy.

## Type
One display face plus one text face. Never Inter, Arial, or Roboto.

## Never
- Purple, indigo, or violet anywhere, especially gradients
- Gradient text on headings
- rounded-2xl on every surface
- Emoji as icons
- Three identical feature cards in a row
- Default shadow-lg on everything
- Em dashes in any copy

## Always
- Crimson is the only accent color, commit to it
- Asymmetry somewhere on every page
- Type scale with real contrast between levels
- After any UI change: open it with Playwright, screenshot it,
  name three things that look generic, fix them before finishing
